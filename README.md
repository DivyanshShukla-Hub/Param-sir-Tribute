## Tribute Website for Pramatma Vishwakarma

A heartfelt one-page tribute website made with respect for our Python Programming Mentor, **Pramatma Vishwakarma**.

## Features
- Fullscreen welcome screen with terminal-style interaction
- Run button animation (`print("Hello Sir ❤️")`)
- Smooth transition to tribute page
- Premium dark developer-themed UI with soft neon glow
- Sir photo section with glowing profile styling
- Emotional gratitude message and heart message section
- Floating animated Python/code-style background snippets
- Background song playback starting from 35 seconds
- Responsive design for mobile, tablet, and desktop
- iOS Safari and cross-browser compatibility improvements
- Accessibility and performance optimizations

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
